# Кіт і лабіринт

Гра на tkinter для Кодика v1.23+ / APK 1.2+ та звичайного Python із Tkinter.

Відкрий cat-maze.py в редакторі й запусти. У міні-IDE його можна додати кнопкою «Додати файли».

Стрілки або WASD рухають кота на одну клітинку; українські відповідники WASD також працюють. Клік чи торкання клітинки задає маршрут до неї. На телефоні є екранні стрілки. Спочатку знайди мишку, потім іди через двері, що стануть зеленими. Мишка йде за котом. Три рівні, випадкові прохідні лабіринти, лічильник кроків і перезапуск.

Для клавіш потрібен фокус у вікні гри: натисни на поле або екранну стрілку. Будь-який ручний рух скасовує автоматичний маршрут.

Використано bind('<Key>'), bind('<Button-1>'), bind('<Motion>'), Canvas.move, after і after_cancel. Пошук шляху — BFS. MazeState відокремлює правила від CatMazeUI. Для малюнків використано фігури Canvas, зовнішні зображення не потрібні.

Перевірено 300 лабіринтів і браузерні клавіші, кнопки, кліки на вузькому екрані, збирання мишки, вихід, перехід рівня, перезапуск та скасування таймера. Нова версія бібліотек чи APK не потрібна.
