# Допомога з помилками Python — v1.31

Перевірка працює локально у вебзастосунку. Код не надсилається на сервер. Використовуються компілятор CPython із Pyodide, структуровані SyntaxError/traceback та **Pyflakes 3.4.0** (MIT; копія ліцензії в licenses/pyflakes.txt). Завантаження додаткових пакетів учнем не потрібне.

## Як користуватися

- «Перевірити код» перевіряє активний файл без виконання його команд, без input() та без побічних ефектів програми.
- «Запустити» спочатку перевіряє синтаксис. Якщо він неправильний, програма не виконується й не просить input().
- Панель показує файл, рядок і стовпець, українське або англійське пояснення, фрагмент коду зі знаком ^ та оригінальні технічні деталі.
- Натисни на назву помилки, щоб перейти до рядка. У Міні-IDE відкриється відповідний файл. Рядок також позначається в редакторі та нумерації.
- Після зміни коду старі позначки цього файла прибираються. Якщо помилка надійшла від ще живого графічного callback зі старої версії коду, перехід пропонує перевірити код знову, а не виділяє довільне місце.

## Що перевіряється

### Синтаксис до запуску

Компілятор Python визначає синтаксичну помилку та позицію. Пояснення охоплюють:

- пропущену двокрапку в if/elif/else, for/while, def/class, try/except/finally, with, match/case;
- незакриті круглі, квадратні та фігурні дужки, зайві закривальні дужки й невідповідні пари;
- незакриті звичайні та потрійні лапки, помилки фігурних дужок у f-рядках;
- типографські лапки й недопустимі/невидимі символи;
- відсутній, зайвий або неузгоджений відступ, змішані табуляції й пробіли;
- імовірно пропущену кому там, де це визначив компілятор;
- присвоювання = замість порівняння == в умові;
- print без дужок у стилі Python 2;
- початкові нулі у десяткових числах, неправильний запис числа або імені;
- return/yield поза функцією, break/continue поза циклом;
- повторний параметр функції, неправильний порядок параметрів або аргументів виклику;
- неправильну ліву частину присвоювання, незавершений try.

Інші синтаксичні помилки також показуються з позицією та оригінальним повідомленням Python; для них підказка може бути загальнішою. Синтаксис не визначається саморобним пошуком двокрапок або підрахунком усіх дужок: лапки, коментарі та багаторядкові конструкції розбирає Python.

### Попередження Pyflakes

- невідомі імена, з підказкою схожого відомого імені, коли вона є;
- локальна змінна, використана до присвоювання;
- повторні ключі словника;
- умова-кортеж, яка завжди істинна;
- is для порівняння літеральних значень замість ==/!=;
- f-рядок без полів підстановки;
- невідповідність аргументів у .format() та %-форматуванні;
- raise NotImplemented замість NotImplementedError.

Це попередження, а не заборона запуску. Стиль, зайві імпорти та невикористані змінні навмисно не засмічують навчальну панель. Імена зі star import, наприклад from robot import *, не позначаються як напевно невідомі. Аналізатор не імпортує модулі учнівського проєкту.

### Помилки під час виконання

З traceback береться останній кадр учнівського коду, а не обгортка середовища. Є пояснення для NameError/UnboundLocalError, ZeroDivisionError, IndexError, KeyError, ModuleNotFoundError/ImportError, AttributeError, TypeError, ValueError, FileNotFoundError, RecursionError та AssertionError. Для інших винятків зберігаються фактичні позиція та технічні деталі з загальнішою підказкою.

Це працює в навчальному режимі, у модулях Міні-IDE та в підтриманих tkinter-callback. Ввід input() залишається реалізованим наявним механізмом середовища; при підстановці відповіді зберігаються переноси рядків. Якщо підстановка змінила стовпці, позначається вихідний рядок, без неправдивого точного стовпця.

## Приклади

~~~python
age = 12
if age > 10
    print("Старший клас")
~~~

Повідомлення: **main.py, рядок 2 — пропущена двокрапка**. Виправлення: if age > 10: .

~~~python
values = []
print(values[0])
~~~

Під час виконання: **рядок 2 — індекс поза межами колекції**. Список порожній; перевір len(values), перш ніж брати елемент.

## Межі перевірки

Жоден із цих інструментів не гарантує знаходження всіх логічних помилок. Компілятор зазвичай повертає першу синтаксичну помилку: виправ її й повтори перевірку. Pyflakes робить статичні припущення, тому його результати не блокують виконання. Помилки значень можуть проявитися лише на конкретних даних під час запуску.

Позиція синтаксичної помилки — місце, яке визначив Python: для деяких неповних конструкцій причина може бути в попередньому рядку. Якщо учнівського кадру немає, середовище прямо повідомляє про відсутність позиції, не вигадуючи номер рядка. Автоматичного переписування коду немає.

Виконується тільки веброзробка; Android-збірка до цієї зміни не входить.
