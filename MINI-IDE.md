# Міні-IDE Кодика

Вебверсія v1.24 / Android 1.3. Перемикач «Міні-IDE» вмикає дерево проєкту поруч із редактором; на телефоні його відкриває кнопка «Файли».

Створюй папки й файли, перейменовуй та видаляй вибрані елементи. Закриття вкладки залишає файл у проєкті. Кнопка «Відновити» повертає стан перед останньою операцією видалення/заміни або перед запуском Python. Простий навчальний режим має окремі вкладки; при першому відкритті IDE вони копіюються в проєкт.

Кнопка запуску виконує поточний файл .py. Python бачить весь проєкт, підтримує імпорт сусідніх модулів та читання/запис відносних файлів від кореня проєкту. Згенеровані файли з'являються в дереві, зокрема після обробників tkinter. При конфлікті з новішими змінами в редакторі версія Python зберігається окремою копією. Кеш імпортованих модулів очищається між запусками. Бінарні файли доступні для Python та експорту, але не редагуються як текст.

«Приклад» відкриває проєкт із main.py, helpers.py та data/names.txt: запусти main.py, і з'явиться result.txt. Попередній проєкт можна відновити.

Проєкт зберігається локально на пристрої. «Зберегти проєкт» експортує всі файли в .kodik.json; «Відкрити проєкт» відновлює таку копію. «Додати файли» імпортує окремі файли. Android використовує системний вибір і збереження документів без дозволу на весь накопичувач.

Це віртуальний проєкт усередині Кодика, а не пряме редагування довільної папки диска. Експортована копія переноситься між пристроями. Очищення даних сайту/застосунку видаляє локальні проєкти; перед цим збережи копію файлом. На Android 9 потрібен WebView 112+.
