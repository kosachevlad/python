Урок 2

Запитуємо й відповідаємо: input() та print()

Навчи програму вести короткий діалог. Ти введеш відповідь у терміналі, а програма використає її в повідомленні чи обчисленні.

Почати урок ↓

1. Програма запитує ім’я

input("Як тебе звати? ") показує запитання й чекає на відповідь. У «Кодику» натисни «Запустити», введи відповідь у полі під терміналом і натисни «Надіслати» або Enter. Змінна name збереже введений текст.

Код Python

name = input("Як тебе звати? ")
print(f"Привіт, {name}!")

Приклад діалогу

Як тебе звати? Оля
Привіт, Оля!
Відкрити в Кодику ↗

Спробуй ввести інше ім’я. У рядку з f значення name підставиться у фігурні дужки.

2. Відповідь завжди є рядком

За замовчуванням input() повертає str — рядок, навіть якщо ввести цифри. Тому "7" + "2" дає "72": рядки з’єднуються. Функція type(...).__name__ покаже тип значення.

Код Python

answer = input("Введи число 7: ")
print("Тип:", type(answer).__name__)
print("Плюс рядок 2:", answer + "2")

Якщо ввести 7

Введи число 7: 7
Тип: str
Плюс рядок 2: 72
Відкрити в Кодику ↗

Перед запуском передбач результат, якщо ввести 15.

3. Перетворюємо відповідь на число

Коли потрібне ціле число, обгорни введення у int(input(...)). Спочатку input() читає рядок, потім int() перетворює його на число. Тепер + додає числа.

Код Python

age = int(input("Скільки тобі років? "))
print("Тип:", type(age).__name__)
print(f"Через рік тобі буде {age + 1}.")

Якщо ввести 13

Скільки тобі років? 13
Тип: int
Через рік тобі буде 14.
Відкрити в Кодику ↗

Вводь ціле число без лапок. Якщо ввести слово або дріб на кшталт 2.5, int() повідомить про помилку перетворення.

4. Два введення — один результат

Запитай два числа окремо. Кожне введення перетвори за допомогою int() і виведи суму через print().

Код Python

apples = int(input("Скільки червоних яблук? "))
pears = int(input("Скільки зелених груш? "))
print(f"Усього фруктів: {apples + pears}")

Якщо ввести 3, потім 4

Скільки червоних яблук? 3
Скільки зелених груш? 4
Усього фруктів: 7
Відкрити в Кодику ↗

Зміни запитання так, щоб програма рахувала не фрукти, а предмети для твоєї гри.

Вправи для тебе

  1. Вітальна листівка. Запитай ім’я та улюблений колір. Виведи два рядки з відповідями, використавши print() і f-рядок.
  2. Квитки. Запитай кількість дитячих квитків. Один квиток коштує 30 грн. Виведи загальну вартість. Для введення кількості використай int(input(...)).
  3. Два рівні гри. Запитай бали за перший і другий рівні, додай їх і виведи підсумок. Перед запуском передбач результат для 8 та 12 балів.
  4. Знайди помилку. Спробуй points = input("Бали: ") та print(points + 5). Поясни помилку й виправ перший рядок, щоб програма додавала 5.
Підказки й самоперевірка

Для квитків: count = int(input("Скільки квитків? ")), а вартість дорівнює count * 30. За два рівні з 8 і 12 балами вийде 20. В останній вправі points є рядком; обгорни input(...) у int(...).
