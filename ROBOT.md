# Robot у Кодику v1.25

Вбудований браузерний порт robot-python 1.0. `pip install` у Кодику не потрібен: `from robot import *` або `import robot` одразу працюють у навчальному режимі та Міні-IDE. Оригінальна модель світу, API та 27 карт взяті з пакета robot-python (MIT). Ліцензія: licenses/robot-python.txt.

## Як перевірити

1. Відкрий examples/robot-start.py в редакторі та натисни «Запустити».
2. Під виводом з’явиться карта. Натисни «Виконати» для анімації або «Крок» для одного переміщення/повороту.
3. Робот пройде маршрут і забере кристал. «Скинути» повертає відтворення на початок, «Стоп» ставить його на паузу.
4. examples/robot-zigzag.py проходить карту map3.map, як на зображенні прикладу.

Карта у списку задає початковий світ наступного запуску Python. `load_map()` та `load_map_text()` у коді можуть його замінити. Після зміни карти натисни «Запустити» ще раз. Власну .map можна відкрити кнопкою під картою або додати в Міні-IDE й викликати `load_map("my.map")`. Вбудовані: map1.map … map27.map.

## Команди

- Рух: forward(n=1), backward(n=1), left(), right(), north(n=1), east(n=1), south(n=1), west(n=1).
- Датчики: frontIsClear(), frontIsObstacle(), frontIsEnergon(), frontIsWhite(), frontIsBlack(); аналогічні leftIs… та rightIs… .
- Фарба: paintWhite(), paintBlack(), stopPainting(), clearPaint(), isPainted(x,y).
- Кристали: pickUp(), collected(), EnergonLeft(), EnergonTotal(). pickUp забирає кристал ПЕРЕД роботом, а не під ним.
- Стан: position(), direction(), setSpeed(0…10), getSpeed(), skin("desert"), get_world(), done()/mainloop().

Зіткнення породжує CollisionError, вихід за карту — OutOfBoundsError. Їх можна перехоплювати try/except. Напрямок стрілки — напрямок руху. Координати від нуля, x вправо, y вниз.

## Відмінності від настільного пакета

Вебадаптер обчислює програму й записує стани світу під час «Запустити», потім кнопки під картою відтворюють цей запис. Умови, цикли, значення датчиків і результати команд обчислюються Python над справжньою моделлю. Вивід print з’являється під час обчислення, до анімації. «Стоп» керує відтворенням, а не перериває довільний Python-код. Ліміт: 10000 звернень до команд robot, 10000 кадрів або 16 млн символів запису. Нескінченні цикли без викликів robot залишаються обмеженням поточного середовища Python.

Замість настільних зображень Pillow використано власний Canvas-рендерер з п’ятьма палітрами. Декоративні extra-об’єкти не малюються; стіни, фарба, робот і кристали відображаються. Імпорт .world, настільне set_program та автоматичний перехід на наступну карту не підтримуються. Звичайні .map, секції direction і paint підтримуються. Завантажена через кнопку власна карта зберігається до перезавантаження сторінки; для постійного збереження додай її до проєкту Міні-IDE.

Android: модуль входить в APK 1.4 (Android 9+). Попередній APK 1.3 його не містить.
