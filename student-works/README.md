# Роботи учнів у Кодику

Галерея з'являється внизу головної сторінки поруч зі «Зворотним зв'язком».

Щоб опублікувати роботу, учитель додає PNG з кнопки «Поділитись кодом і виконанням» у папку `student-works/` та додає запис до `student-works.json` (кореневий каталог).

Приклад запису (це лише приклад, не публікувати як реального учня):

```json
[
  {
    "id": "work-001",
    "surname": "Прізвище",
    "date": "2026-11-14",
    "image": "student-works/work-001.png",
    "code": "print('Привіт, світе!')\n"
  }
]
```

- `id` — унікальний та незмінний ідентифікатор роботи. Його використовує браузер для запам'ятовування лайка.
- `surname` — прізвище/підпис учня (публікувати лише за належної згоди).
- `date` — дата публікації у форматі YYYY-MM-DD.
- `image` — шлях до PNG, який показує код та виконання.
- `code` — справжній вихідний Python-код, який копіюється в нову вкладку редактора при натисканні «Спробувати».

Сторінка статична (GitHub Pages): роботу додає власник репозиторію, учні самостійно не публікують її на сервер. Лайки зберігаються лише в `localStorage` конкретного браузера: повторний лайк із цього браузера заблокований, але **спільний лічильник не підтримується** й інші браузери / очищення даних дають можливість лайкнути знову. Для реальних загальних підрахунків потрібен сервер чи база даних.
