Урок 1

Типи даних і print()

Розпізнай цілі й дробові числа, текст і логічні значення. Навчися виводити їх у термінал.

Почати урок ↓

1. Перший рядок у терміналі

Напиши print() і в дужках передай текст у лапках. У «Кодику» натисни «Запустити». Термінал покаже текст без лапок.

Код Python

print("Привіт, Python!")
print("Це мій перший урок.")

Очікуваний вивід

Привіт, Python!
Це мій перший урок.
Відкрити в Кодику ↗

Заміни привітання власним повідомленням і додай третій рядок із print().

2. Чотири типи даних

int
Від англ. integer — «ціле число». Наприклад, 8.
float
Від англ. floating-point number — «число з плаваючою точкою». Так можна записати дробове число, наприклад 1.5. У коді ставимо крапку.
str
Від англ. string — «рядок». Текст можна записати в подвійних лапках "8" або в одинарних '8'. Для тексту на кілька рядків зручні потрійні лапки """…""" або '''…'''. Зворотна лапка ` у Python 3 не позначає початок чи кінець рядка.
bool
Від англ. Boolean — «булевий». Це логічне значення True або False. Пишемо з великої літери й без лапок.

Тип показує, що це за значення. Функція type() визначає тип, а .__name__ дає його коротку назву.

Код Python

print(type(8).__name__)
print(type(1.5).__name__)
print(type("8").__name__)
print(type(True).__name__)

Очікуваний вивід

int
float
str
bool
Відкрити в Кодику ↗

Порівняй 8 і "8". Яке з цих значень можна додати до числа 2?

3. Текст, значення й обчислення

Збережи дані у змінних. У print() перелічуй значення через кому. Python зазвичай ставить між ними пробіл і переходить на новий рядок після кожного виклику.

F-рядок. Постав літеру f перед відкривальними лапками й напиши ім’я вже створеної змінної у фігурних дужках. У виклику print(f"Ім’я: {name}") Python підставить поточне значення name замість {name}. Зміни name і запусти код знову, щоб побачити нове ім’я в терміналі.

Код Python

name = "Робот К-8"
points = 7
height = 1.5
ready = True

print(f"Ім’я: {name}")
print("Зріст:", height, "м")
print("Готовий:", ready)
print("Бали після бонусу:", points + 2)

Очікуваний вивід

Ім’я: Робот К-8
Зріст: 1.5 м
Готовий: True
Бали після бонусу: 9
Відкрити в Кодику ↗

Зміни кількість балів і перед запуском передбач, яким буде останній рядок.

Самостійна робота. Картка персонажа

  1. Вигадай персонажа і створи для нього чотири змінні. Запиши ім’я, кількість балів, зріст із дробовою частиною та стан готовності.
  2. Виведи всі чотири значення в термінал із підписами. Наприклад, print("Бали:", points).
  3. Додай ще один виклик print(), який покаже кількість балів після бонусу в 5 балів.
Самоперевірка

У терміналі має бути п’ять рядків. У кожному видно підпис і значення. Якщо початкових балів було 7, в останньому рядку має бути 12.
